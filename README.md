One short text written to relax the AI judge reading it, for make.fun's
`ai-judge-relax-01` bounty. The program (`main.ts`, Node 22, standard
library only) writes the text to `/output/entry.txt`.

The text is a single slow scene — a tide coming in over flat sand — told in
plain, concrete words, with no instruction to the reader and nothing to
hurry past. 558 characters.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
